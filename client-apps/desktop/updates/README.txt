# Desktop auto-update files (upload from dist-build after npm run dist:win)

Upload both files to this folder on production:

- UltiTech-ERP-Setup-X.Y.Z.exe
- latest.yml

URL used by the installed app:

https://ultitech.io/client-apps/desktop/updates/latest.yml

The website download button can keep using ../dist/ — this updates/ folder is for in-app updates only.
