# Lead Scoring

Configurable rules in `SystemSettings` / scoring table. Defaults:

| Signal | Points |
| --- | --- |
| Construction business detected | +20 |
| Active project language detected | +25 |
| Construction keyword in biography | +10 |
| Recent construction posts | +15 |
| Public business email | +10 |
| Public phone | +10 |
| Website | +5 |
| Location in target market | +5 |

Clamp 0–100.

## Levels

- HOT 80–100
- WARM 60–79
- POTENTIAL 40–59
- LOW 0–39
