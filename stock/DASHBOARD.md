# Stock Dashboard

React stock home for new and returning users. Replaces the older PHP/Chart.js dashboard with a guided desk: clear actions first, then metrics and activity.

## URL

| Entry | Resolves to |
| --- | --- |
| `/stock/` or `/stock/index.php` | Redirect ? `dashboard.php` |
| `/stock/dashboard.php` | React dashboard shell |
| `/{company_slug}/stock/?module=stocks` | Same via company rewrite (e.g. Ultimate) |

Example:

```
http://localhost/public_html/ultimate/stock/?module=stocks&company_slug=ultimate
```

## Architecture

```
Browser
  ?? stock/dashboard.php          PHP: auth, queries, payload, shell
        ?? window.__STOCK_PAGE__  { page: 'dashboard', data: {...} }
        ?? stock-ui/dist          stock-ui.js + stock-ui.css
              ?? App.jsx ? Dashboard.jsx + dashboard-desk.css
```

| Layer | File | Role |
| --- | --- | --- |
| Backend shell | `stock/dashboard.php` | Login, stock stats SQL, JSON bootstrap, ERP header/footer |
| Router | `stock/stock-ui/src/App.jsx` | `page === 'dashboard'` |
| UI | `stock/stock-ui/src/pages/Dashboard.jsx` | Layout and interactions |
| Styles | `stock/stock-ui/src/pages/dashboard-desk.css` | Desk layout, teal accent, responsive grids |
| Build | `stock/stock-ui/` (`npm run build`) | Outputs `dist/assets/stock-ui.js` + `.css` |

Assets always load from `app_url('/stock')` so company-slug URLs still hit the shared `stock/stock-ui/dist` bundle.

### Empty catalogue (`total_products === 0`)

Only hero + empty state:

- Message: catalogue is empty  
- Primary CTA: **Add your first product**

### Responsive breakpoints

| Width | Behavior |
| --- | --- |
| ?992px | Action grid 2×2; metrics 4 columns; restock / purchases side by side |
| &lt;992px | Metrics 2 columns; panels and insight stack to one column |
| &lt;640px | Action tiles single column; hero CTAs stretch full width |

## Section reference

| Section | Purpose | Links to |
| --- | --- | --- |
| Hero | Brand + primary next steps | Add product, New purchase (domestic create) |
| Common tasks | Four guided destinations | Add / Purchase / Products / Shipments |
| At a glance | Counts + stock-health bar | Products, low-stock filter, suppliers |
| Needs restock | Items at or below reorder (incl. out) | Product view |
| Recent purchases | Latest POs + today’s total footnote | Purchase view / purchases list |
| Moving this month | Product of week + 30-day outgoing | Product view |
| More tools | Secondary nav | Movements, suppliers, uploads |

## Data payload

PHP sets `window.__STOCK_PAGE__`:

```js
{
  page: 'dashboard',
  data: {
    company_name,
    date_label,
    total_products,
    in_stock,
    low_stock,
    out_of_stock,
    total_suppliers,
    today_purchases_total,
    products_growth_pct,
    outgoing_units,
    low_stock_items: [{ id, name, product_code, quantity, reorder_level, status, image_url }],
    recent_purchases: [{ id, supplier_name, product_name, product_code, total_amount, status, created_at, image_url }],
    top_sellers: [{ id, name, quantity, image_url }],
    product_of_week: { id, name, quantity, image_url } | null,
    links: {
      products, products_low, add_product,
      purchases, purchase_create, purchase_view,
      suppliers, shipments, movements, uploads, product_view
    }
  }
}
```

## Design notes

- Root class: `.dash-desk` (system font via `--erp-font-family`)
- Accent: teal (`#0f766e`), slate neutrals, light `#f8fafc` page background
- Soft rise animation on sections; no Chart.js
- Dark theme: `html[data-theme="dark"]` overrides in `dashboard-desk.css`

## Develop / build
