# 🏪 Stock Management System

## 📋 System Purpose
A complete **End-to-End Inventory & Procurement Solution** designed to streamline operations from purchase order to warehouse storage. 

**Key Objectives:**
*   **Track Stock:** Real-time visibility of inventory levels and locations.
*   **True Landed Cost:** Automate the calculation of product costs including duty, freight, and insurance.
*   **Efficiency:** Reduce manual data entry with automated status updates and batch tracking.
*   **Intelligence:** Low stock alerts, expiry tracking, and supplier performance metrics.

## 👥 Target Users
| Role | Primary Responsibilities |
| :--- | :--- |
| **Procurement Officer** | manage POs, communicate with suppliers, handle shipments. |
| **Warehouse Staff** | receive goods, check quality, manage stock locations. |
| **Management** | view reports, approve large orders, analyze profitability. |
| **Sales Team** | view stock availability and product catalogue. |

## 🛠️ Technology Stack
*   **Backend:** PHP 8 (PDO, Object-Oriented)
*   **Database:** MySQL 8
*   **Frontend:** Bootstrap 5, jQuery, Chart.js
*   **Visuals:** FontAwesome, Google Fonts (Inter)

## 🚀 Key Modules
1.  **Dashboard:** Real-time overview of stock value, incoming shipments, and alerts.
2.  **Product Catalogue:** robust management of items, images, and prices.
3.  **Purchase Orders:** complete lifecycle from Draft -> Approved -> Received.
4.  **Shipments:** granular tracking (ETD, ETA, Customs) and Landed Cost engine.
5.  **Stock Control:** batch tracking, expiry dates, and automated movements.
6.  **Reporting:** detailed analytics for finance and operations.
