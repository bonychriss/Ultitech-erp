# Stock Settings Frontend

This folder contains a small Vite + React + Tailwind app for the settings page.

Install and build (requires Node.js >= 16):

```bash
cd stock/frontend
npm install
npm run build
```

During development:

```bash
npm run dev
```

After `npm run build` the compiled assets will be in `stock/frontend/dist` and `settings.php` will automatically load them.
