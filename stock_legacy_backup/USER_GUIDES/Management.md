# 📊 Management & Admin Guide

## Role Overview
As a **Manager or Admin**, you oversee the entire lifecycle, manage user permissions, and analyze financial performance.

## Key Responsibilities

### 1. User Management
1.  Go to **Settings > Users**.
2.  Create new accounts for staff.
3.  Assign Roles:
    *   **Admin:** Full access.
    *   **Procurement:** Can buy and edit costs.
    *   **Warehouse:** Can only update stock moves.
    *   **Viewer:** Read-only access.

### 2. Financial Reporting
Access **Reports** to view:
*   **Stock Valuation:** Real-time value of asset inventory.
*   **Landed Cost Analysis:** See how much duty/freight is adding to unit costs.
*   **Profitability:** (If sales data is linked) Margins based on true landed cost.

### 3. Approvals
*   Drafter POs showing as "Pending" require your approval.
*   Review the **Total Amount** and **Budget** before clicking **Approve**.

## System Maintenance
*   **Backups:** Ensure the IT team runs the daily SQL export.
*   **Audit Logs:** Check `Activity Log` periodically to spot unusual stock adjustments.
